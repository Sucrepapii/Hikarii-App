# Contributing to Hikari

Thank you for your interest in contributing to **Hikari**! We welcome contributions from everyone to help make this project better.

## How to Contribute

### 1. Reporting Bugs

- Open an issue on GitHub.
- clearly describe the issue, including steps to reproduce.
- Include screenshots or error logs if possible.

### 2. Suggesting Enhancements

- Open an issue on GitHub.
- Describe the feature you'd like to see and why it would be useful.

### 3. Pull Requests

1.  **Fork the repository** on GitHub.
2.  **Clone your fork** locally:
    ```bash
    git clone https://github.com/your-username/hikari.git
    ```
3.  **Create a branch** for your feature or fix:
    ```bash
    git checkout -b feature/amazing-feature
    ```
4.  **Commit your changes** with descriptive messages.
5.  **Push to your branch**:
    ```bash
    git push origin feature/amazing-feature
    ```
6.  **Open a Pull Request** to the `main` branch of the original repository.

## Development Guidelines

- **Code Style**: Follow the existing code style (Prettier/ESLint are configured).
- **Type Safety**: Avoid using `any` types in TypeScript whenever possible.
- **Testing**: Test your changes thoroughly before submitting.
- **Commits**: Use clear, present-tense commit messages (e.g., "Add feature X" not "Added feature X").
